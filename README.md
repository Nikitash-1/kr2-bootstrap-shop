# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина суккулентов «Эхеверия.world», разработанную с использованием Bootstrap 5.3.8.

## Git Pages

https://nikitash-1.github.io/kr2-bootstrap-shop/

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ;
- сетка популярных товаров;
- подвал страницы.

## Практическая работа 10

Тема: «Страница на Bootstrap: компоненты».

Выполнено:

- добавлена единая Bootstrap-навигация;
- создана страница каталога `catalog.html`;
- создана страница товара `product.html`;
- создана страница заявки `order.html`;
- использованы компоненты `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `form-control`, `input-group`, `form-check`, `accordion`;
- добавлен файл `css/custom.css` для минимальных доработок;
- проект подготовлен к сдаче контрольной работы №2.

## Практическая работа 11

Проект приведён к итоговому виду.

Выполнено:

- проверена структура проекта и все обязательные страницы;
- единая навигация с активным пунктом меню на каждой странице;
- каталог расширен до 6 товаров (2 со статусом «Новый», 2 со статусом «Скидка»);

- обновлены тексты страниц под предметную область «суккуленты»;
- обновлён `README.md`.

## Используемые технологии

- HTML;
- Bootstrap 5.3.8 (CDN);
- CSS;
- Git;
- GitHub.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница товара;
- `order.html` — форма заявки;
- `css/custom.css` — переопределение цветовой темы и дополнительные стили;
- `images/` — изображения товаров и баннер;
- `README.md` — описание проекта.

## Реализованные Bootstrap-компоненты

- `navbar` (с выпадающим меню);
- `card` (карточки товаров);
- `btn` (основные и контурные варианты);
- `badge` (метки «Новинка», «Хит», «Скидка», «Новый»);
- `alert`;
- `modal` (быстрая заявка в каталоге);
- `form-control`, `form-select`, `input-group`, `form-check`;
- `accordion` (частые вопросы);
- `breadcrumb` (страница товара);
- `table` (характеристики товара);
- сетка `container`, `row`, `col-*`, `g-*`.

## Самостоятельные доработки

- расширение каталога до 6 товаров с разными статусами;
- добавление изображений в карточки и баннера на главной;
- переопределение цветовой темы Bootstrap через `custom.css` (салатовый акцент, тёмно-зелёный фон навигации и подвала);
- добавление breadcrumb и таблицы характеристик на страницу товара;
- адаптация всех текстов под предметную область «суккуленты»;
- раскрывающееся меню «Дополнительно» в навигации.
